SVG Palette Processor

Parse SVG files, extract fills, strokes, and gradient stops into a JSON palette, and rewrite solid colors as reusable linearGradient definitions.

View on GitHub

CLI usage

npm install
node bin/svg-processor.js fixtures/input.svg
# or
svg-processor input.svg -o updated.svg -j palette.json

Outputs an updated SVG with <defs id="generated_def"> and a structured palette JSON.

View on GitHub

Try it locally

Clone the repo, run the CLI on any SVG, and inspect svg_json.json for fills, strokes, gradients, and obsolete gradient references.
